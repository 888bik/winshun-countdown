# 倒计时

Win顺 的原生 Go 倒计时插件。输入标题和时长，按 Enter 开始；可同时运行多个倒计时，关闭搜索窗口后仍在后台计时。到期通过独立悬浮窗或 Win顺 系统通知提醒，并支持声音提示和任务栏托盘图标。

- 插件 ID：`me.countdown`
- 版本：`1.7.0`
- 运行时：`countdown.exe`，Go 标准库，无 Python、无第三方依赖
- `minWinShun: "0.22.0"`：未审核原生插件的最低宿主版本要求；`eager` 常驻启动在该版本也可用。
- `memoryMB: 64`：宿主与官方 Schema 要求最小 64 MB；任务说明中的 32 MB 低于宿主允许值，不能写入合法 manifest。64 是作业上限，不代表实际占用。

## 使用

输入 `倒计时` 查看待确认、正在运行和已暂停的计时器：

```text
泡面
剩余 02:35 · 12:25 结束 · Enter 取消
```

输入标题和时长创建：

```text
倒计时 泡面 3
倒计时 午休 25m
倒计时 会议 1h30m
倒计时 90s
倒计时 25
```

最后一个独立参数是时长，前面的文字都是标题；只写时长时标题默认是「倒计时」。

空输入时，现有计时器列表后面还会固定显示 9 个一键预设：`5 / 10 / 15 / 25 / 30 / 45 / 60 分钟`、`番茄专注`（25 分钟）和 `休息`（5 分钟）。按 Enter 就开始对应计时；预设不会自动串联，番茄专注结束后不会自动开始休息。列表没有计时器时，预设行会替代原来的空状态提示。手动输入非空内容时只显示手动解析结果，不显示预设。

支持：

- 纯数字：`25` = 25 分钟
- 秒：`90s`、`90秒`
- 分钟：`25m`、`25分`
- 小时：`1h`、`1时`、`1小时`
- 组合：`1h30m`、`1h30m10s`、`1小时30分`
- 分秒：`25:00`

不支持小数、负数、`0`、`25:99`、超过 365 天或无法解析的输入。最短 1 秒，最长 365 天。解析失败只显示提示，不会创建计时。

合法时长先显示一行「开始倒计时：泡面」，按 Enter 才真正创建。创建后按 `floating_window` 设置使用悬浮窗或系统通知提醒。最多同时运行 20 个；已暂停和待确认项目不占运行名额。运行中的计时器可通过第二个动作暂停、第三个动作重新开始；暂停项排在列表最后，按 Enter 继续，第二个动作取消。

输入 `倒计时` 先列出待确认项目，再列出正在运行的项目：

```text
泡面
已经结束，等待确认。 · Enter 确认已知晓

午休
剩余 24:18 · 12:30 结束 · Enter 取消 · 其他动作：暂停 / 重新开始

会议
已暂停，剩余 12:30 · Enter 继续
```

## 到期确认与重复提醒

倒计时到期不会直接删除。状态从 `running` 变成 `pending_ack`，必须先持久化再触发提醒；用户确认后才从列表移除。

- 首次到期立即提醒：`floating_window` 开启时显示独立悬浮窗；关闭时发系统通知：`泡面倒计时已结束。点我打开列表，按 Enter 确认。`
- 首次重复提醒在到期后 15 秒，之后每 60 秒一次，直到确认。
- 原始总时长超过 60 秒的 running 计时器，会在预计结束前 1 分钟额外收到一条系统 toast：`还有 1 分钟到期：标题`。这条预提醒只发 toast，不播放声音、不弹悬浮窗、不改变计时器状态；每次运行最多一次。总时长 60 秒及以下不触发。暂停期间不提醒，继续后会按新的结束时间重新计算；重新开始会重置预提醒标记。
- 提醒时间用绝对时间 `nextReminderAt` 持久化，不依赖内存减数。
- 多个待确认项目合并成一条通知。
- `floating_window` 开启时，可点悬浮窗中的“已知晓”或列表里的待确认行按 Enter 确认；关闭时，点通知只会通过 `setQuery` 打开 `倒计时 ` 列表，再按 Enter 确认。点通知本身不会自动确认。
- 只有结果行的 Enter `acknowledge` 动作才会确认；确认后停止该计时器所有后续提醒。
- `pending_ack` 和 `paused` 都不占 20 个 `running` 名额；继续或重新开始时会再次检查运行数量上限。
- 运行中项目：Enter 取消，第二个动作暂停，第三个动作重新开始。
- 已暂停项目：Enter 继续，第二个动作取消；暂停期间不参与到期调度，剩余秒数会持久化。
- 待确认项目：Enter 确认，第二个动作稍后提醒，第三个动作重新开始。重新开始恢复创建时的原始时长，并清空到期/重复提醒状态。

## 悬浮窗

1.2.0 增加一个独立的 Win32 悬浮窗，作为通知和列表之外的确认入口。`floating_window` 开着时，到期/重复提醒/启动恢复**只弹悬浮窗，不再同时发系统通知**；关掉后完全回到 1.1.0 的“通知 + 列表”行为。它只在有 pending_ack 时弹出，查询和动作处理期间不会抢前台。列表（搜索框）打开时先不弹，等最后一次 `countdown` query 结束 2.5 秒后再弹。

- 窗口固定在主显示器右下角、任务栏工作区上方，客户区约 340 逻辑像素宽，高度随待确认项增长；每行 52 逻辑像素，超过 6 条可滚动，最大 480 逻辑像素；按 DPI 缩放。
- 每行是标题、`已结束`、原生 `稍后提醒` / `已知晓` 按钮；底部是原生 `全部稍后提醒` / `全部已知晓` 按钮，带系统 hover/按下状态。
- 点单条只确认那一条；点全部确认所有；没有待确认项时窗口自动收起。
- 点“稍后提醒”会把该计时器改回 `running`，在 `snooze_minutes` 分钟后重新到期并重新走完整提醒流程；待确认行在列表里也有第二个“稍后提醒”动作。
- 点标题栏 × 只隐藏窗口，**不算确认**；计时器仍是 `pending_ack`，下次重复提醒时同一个窗口重新弹出。
- 在搜索列表里按 Enter 确认也会立即同步到悬浮窗。
- 若悬浮窗创建失败，会退化为发一条系统通知，避免到期无人提醒。
- 设置项 `floating_window`（标题“到期弹出悬浮窗”）默认开启；关闭后立即收起窗口，行为和 1.1.0 一致，只有通知和列表。
- `auto_close_seconds`：悬浮窗自动关闭秒数，0–600，默认 0（永不自动关）。>0 时鼠标进入、点击、按键都会重置；自动关闭只隐藏，不确认，下一次重复提醒会再弹。如果这个值 >= 重复提醒间隔，窗可能刚关又弹，这是设置组合效果，不是 bug。
- `snooze_minutes`：稍后提醒默认分钟数，1–120，默认 5。
- `repeat_first_seconds`（5–300，默认 15）和 `repeat_every_seconds`（10–3600，默认 60）：到期后第一次重复和之后每次重复的间隔。`animations`（默认 true）控制悬浮窗滑入/淡出；系统“动画效果”关闭时自动跳过。1.6.1 将入场/退场时长调整为 220/160ms，帧间隔约 10ms；仅在动画期间短暂请求更高的系统定时器分辨率，结束后立即释放。系统负载较高或窗口被遮挡时，Windows 仍可能合并帧。

默认提醒节奏：到期立即提醒一次 → 15 秒后第一次重复 → 之后每 60 秒一次，直到确认或稍后提醒。刚到期的头几十秒人最可能只是晚了几秒回来，所以先给一次快提醒；之后用稳定的一分钟节奏，既不容易错过，也不会每几秒骚扰。`snooze_minutes` 是稍后提醒的一次性延后（分钟级）；`repeat_*_seconds` 是持续提醒节奏（秒级），两者不要混用。

`ui` 权限只用于创建这个窗口；不申请 `elevated`。

### 声音提示

- `sound_enabled`：到期声音提示，默认开启。首次到期和每次重复提醒都会播放一次；关闭后不播放。
- `sound_file`：自定义提示音，设置项使用文件选择器，只接受有效的 `.wav`（RIFF/WAVE）文件。留空时使用 Windows `SystemAsterisk` 系统声音；使用 Windows `PlaySoundW` 的 `SND_ALIAS` 播放 `SystemAsterisk` 系统音。
- 选择文件后会检查扩展名、RIFF/WAVE 标识、`fmt ` 音频格式块和非空 `data` 数据块；不是 WAV、文件损坏、路径不存在或是目录时立即弹出提示。到期播放时再次校验，任何无效文件都回退到默认系统声音，不影响计时和通知。
- Win顺 当前 `file` 类型设置没有扩展名筛选字段，因此系统文件选择器仍可能显示其他格式；插件会在选择后校验并拒绝把无效文件交给 `PlaySoundW`。
- 用户确认或稍后提醒时停止当前播放；声音使用异步播放，不阻塞调度器。

### 弹窗位置

- `popup_center`：默认关闭。关闭时保持 1.4.0 的显示器工作区右下角位置；开启时将悬浮窗放在当前最近显示器工作区的中央。切换设置后立即重新定位。
- 两种位置都避开任务栏工作区；窗口尺寸和字体仍按 Per-Monitor DPI 缩放。

## 任务栏托盘图标

1.6.0 新增独立的 Windows 通知区域图标，与到期悬浮窗是两套独立窗口。`tray_icon` 默认开启；图标由插件进程自己创建，不依赖外部 `.ico` 文件。关闭该设置会立即删除图标，重新开启不需要重启插件。

- 右键或左键点击图标都会打开动态菜单；菜单在打开时读取当前计时器快照，依次列出运行中、已暂停和待确认项目。
- 运行中项目可直接暂停、取消或重新开始；已暂停项目可继续或取消；待确认项目可确认、稍后提醒或重新开始。动作复用插件现有计时器逻辑，状态变化后菜单提示文本会更新。
- 菜单最多列出 20 个计时器；更多项目会显示数量提示，可去倒计时列表查看。
- 鼠标悬停提示显示运行中数量、最近到期时间和待确认数量。
- 有 running 计时器时，托盘蓝色时钟图标中央显示最先到期项目的剩余整分钟数，向上取整；超过 99 分钟显示 `99+`。paused / pending 不参与计算；没有 running 项目时恢复纯时钟图标。
- 菜单中的“打开倒计时列表…”受 Win顺 协议限制，采用两步中转：点击菜单项后先弹出系统通知，再点击该通知打开已填入 `倒计时 ` 的搜索列表；不是直接打开搜索框。
- `tray_icon`：任务栏托盘图标（右键查看运行中的倒计时），默认开启；设置变更立即生效。托盘图标不需要额外权限，原有 `notifications` 和 `ui` 权限保持不变。

## 后台与恢复

计时器由单个 `time.Timer` 按最近到期时间驱动；没有计时器时 scheduler 完全阻塞，有计时器时最长每 30 秒醒一次作为睡眠/时钟变更保险。窗口 GUI 线程使用阻塞式 `GetMessageW`，隐藏且无动画时不轮询；自动关闭、动画和活动重置都由窗口消息/定时器驱动。搜索窗口关闭后仍然计时。列表正在显示时，到期/重复提醒/确认后会发送 `winshun/refresh`。

数据保存在 `initialize` 的 `params.dataDir/countdown.json`，使用临时文件 + 同目录原子替换。v2 格式记录 `status`、`endedAt`、`nextReminderAt`、`reminderCount`、`originalSeconds`、可选的 `preReminded` 和暂停时的 `remainingSeconds`。`preReminded` 记录当前一轮运行是否已经发过到期前 1 分钟提醒；旧 v2 记录缺少该字段时默认 false，无需手动迁移。数据版本仍为 v2；新增秒数字段为可选字段。旧 v2 记录缺少 `originalSeconds` 时，会自动按 `endsAt - createdAt` 回填（至少 1 秒），无需手动迁移。暂停记录保存为 `status: "paused"`，`endsAt` 清空并写入 `remainingSeconds`。v1 文件会自动迁移：未到期恢复为 `running`，已到期转为 `pending_ack`，不会直接清除；迁移后原子写回 v2。重启后 pending 按 `nextReminderAt` 继续提醒。

通知没有送达确认，跨进程崩溃边界下仍是 at-most-once；确认和提醒由同一把锁串行化，确认成功后不会再发该计时器的提醒。

文件损坏时会报告错误并且不静默覆盖原文件。

## 权限与通知

申请 `notifications` 和 `ui`。`ui` 只用于创建独立悬浮窗；不申请 `elevated`，不需要管理员权限。从 1.1.0 升级到 1.2.0 新增了 `ui` 权限，Win顺 需要用户重新确认一次新增权限。

系统通知由 `winshun/notify` 的 `toast=true` 发送；Win顺 对通知有限速（每插件每 2 秒最多一条，等待队列只保留最新一条），插件已把同批到期合并为一条。声音由插件通过 Windows 异步声音 API 播放，不依赖 Win顺 通知声音设置。

## 构建

需要 Go 1.22+，以及 Windows SDK 的 `mt.exe`（用于把 `countdown.exe.manifest` 嵌入 exe）：

```powershell
.\build.ps1
```

脚本会执行 `go vet ./...`、`gofmt -l .`、`go test ./...`，然后设置 `GOOS=windows GOARCH=amd64 CGO_ENABLED=0` 构建 `countdown.exe`，用 `mt.exe` 嵌入 Common Controls v6 manifest 并校验 `Microsoft.Windows.Common-Controls` 字符串，最后用刚构建的二进制跑协议冒烟测试。

## 数据文件

```text
<params.dataDir>/countdown.json
```

格式：

```json
{
  "version": 2,
  "timers": [
    {
      "id": "...",
      "title": "泡面",
      "createdAt": "RFC3339",
      "endsAt": "RFC3339",
      "status": "pending_ack",
      "endedAt": "RFC3339",
      "nextReminderAt": "RFC3339",
      "reminderCount": 1,
      "originalSeconds": 180
    },
    {
      "id": "...",
      "title": "午休",
      "createdAt": "RFC3339",
      "endsAt": "",
      "status": "paused",
      "originalSeconds": 1500,
      "remainingSeconds": 720
    }
  ]
}
```

`status` 为 `running`、`pending_ack` 或 `paused`。`originalSeconds` 保存创建时总时长；暂停时 `remainingSeconds` 保存暂停瞬间的剩余秒数。已确认记录不会写回文件。

## 限制

- 通知没有送达确认，进程崩溃边界下是 at-most-once。
- 待确认状态不会自动消失；可由列表 Enter、悬浮窗按钮确认，或通过“重新开始”重新计时。
- 重启恢复时如果清除过期记录写盘失败，会记录错误，不发送可能重复的通知。
- 自定义声音只支持结构有效且可由 Windows 解码的 WAV 文件；不支持 MP3、FLAC 等格式。系统默认声音使用 Windows `PlaySoundW` 的 `SystemAsterisk` 别名。文件选择器本身不限制扩展名，插件会在选择后及播放前校验 RIFF/WAVE 结构。
- 悬浮窗位置仅支持当前最近显示器工作区的右下角或中央；悬浮窗本身不进入任务栏或 Alt+Tab，托盘图标由独立隐藏窗口管理。
- 托盘数字与最近到期 tooltip 由最长 30 秒一次的调度器刷新；分钟数字通常在分钟边界更新，最迟可能晚约 30 秒跳变，属于正常行为。
- 自定义提示音通过 Win32 `PlaySoundW` 播放；校验通过只代表 RIFF/WAVE 容器结构完整，音频编码仍需为 Windows 可解码格式，无法播放时回退系统默认音。
- 内存预算 64 MB 是宿主作业限制；正常 Go 运行预计十几 MB，不构成实际占用保证。
- 如果 Win顺 宿主直接强制终止插件进程，插件可能来不及调用 `Shell_NotifyIconW(NIM_DELETE)`，托盘图标可能短暂残留；鼠标划过后 Windows 通常会清理失效图标。
- 托盘菜单的“打开倒计时列表…”不能直接调起 Win顺 搜索框，必须先点击菜单项弹出的系统通知，再点击通知打开列表。
